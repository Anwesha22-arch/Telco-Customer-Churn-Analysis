# Telco Customer Churn Analysis 📊

This repository contains my internship project on **customer churn analysis** using the Telco Customer Churn dataset.  
The project focuses on **data exploration, pivot-table analysis, and data visualization** using **Excel and Google Sheets**.

---

## 🔍 Project Objective

The objective of this project is to analyze customer churn patterns and understand how factors such as **tenure**, **monthly charges**, **gender**, and **service usage** influence customer retention.

---

## 📁 Project Tasks

### **Task 1: Data Overview and Sorting**
- Explored the dataset structure and attributes
- Identified key variables related to churn
- Sorted and summarized churn data for initial insights

---

### **Task 2: Churn Count Visualization**
- Calculated the number of churned vs non-churned customers
- Created a column chart to visualize churn distribution

---

### **Task 3: Monthly Charges Distribution**
- Analyzed the distribution of MonthlyCharges
- Created a histogram to identify pricing patterns and customer concentration

---

### **Task 4: Churn Rates by Gender**
- Built a pivot table to calculate churn counts by gender
- Created a clustered bar chart comparing churned and non-churned customers across genders

---

### **Task 5: Heatmap – Tenure vs Monthly Charges**
- Grouped customers by tenure ranges and monthly charge ranges
- Created a pivot table to analyze interaction between tenure and monthly charges
- Applied conditional formatting to generate a heatmap
- Identified high-density customer segments visually

---
